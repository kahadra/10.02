## 조작

- `←` / `→`, `PageUp` / `PageDown`: 이전·다음
- `M`: 슬라이드 맵 / 번호 입력: 해당 장으로 이동
- `N`: 현재 장의 발표 대본 / `F`: 전체 화면
- 그림·표·수식 클릭: 확대 / `Esc`: 닫기
- `T` 또는 하단 **시작**: 20분 타이머 시작·일시정지·재개
- 하단 `↺`: 타이머를 20분으로 초기화
- `Home`: 첫 장 / `End`: 전체 자료 마지막 장(부록)

본편 22장에서 다음 버튼·오른쪽 키를 눌러도 부록으로 넘어가지 않습니다. **질의응답용 부록 열기** 또는 슬라이드 맵으로 명시적으로 이동합니다. 타이머는 이동·대본 열기 중에도 계속 동작하며, 같은 탭 새로고침 시 상태가 유지됩니다.

## 실행

`index.html`을 Edge 또는 Chrome에서 엽니다. 다른 컴퓨터로 옮길 때는 이 폴더 전체를 복사합니다. `.work/`는 제작·검증용이므로 발표에는 필요하지 않습니다.

- 좌우 화살표, PageUp/PageDown: 슬라이드 이동. `Home`: 첫 장. `End`: 본편 마지막 장.
- `M`: 슬라이드 목록과 번호 이동. `N`: 현재 장의 발표자 노트. `F`: 전체 화면.
- 그림·표·수식을 클릭: 원문 크기로 확대. `Esc`: 확대 화면 닫기.
- `T` 또는 하단 **시작**: 타이머 시작·일시정지. 하단 되돌림 버튼: 초기화.
- 본편 24장 뒤에는 다음 버튼으로 자동 진입하지 않습니다. 부록은 목록에서 선택합니다.

본편 19:00은 대본의 배정 시간을 합한 값입니다. 20분 준수와 이미지 확대에 걸리는 시간은 실제 발표 리허설에서 확인해야 합니다. 실험 수치는 논문 보고값이며 이 자료에서 모델을 재실행하거나 성능을 재현하지 않았습니다.
